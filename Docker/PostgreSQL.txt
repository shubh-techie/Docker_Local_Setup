1. Check what is installed

Run:

brew list | grep -E "mongo|redis"

You may see something like:

mongodb-community
mongodb-database-tools
mongosh
redis


2. Uninstall MongoDB

If installed as mongodb-community:

brew uninstall mongodb-community

If you have a versioned package:

brew uninstall mongodb-community@8.0

If you also have the shell:

brew uninstall mongosh

If you have MongoDB tools:

brew uninstall mongodb-database-tools
